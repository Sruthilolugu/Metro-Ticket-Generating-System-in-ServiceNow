# Metro Ticket Generating System in ServiceNow

## Project Description
The Metro Ticket Generating System is developed using ServiceNow to simplify metro ticket booking. Users can select their source station, destination station, journey date, and number of passengers. The system calculates the fare automatically and generates a ticket confirmation.

## Features
- Select source and destination stations.
- Choose journey date and number of passengers.
- Automatically calculate ticket fare.
- Generate ticket requests and confirmations.
- Provide QR code ticket details.
- Admin management for stations and fares.

## Technologies Used
- ServiceNow
- Service Catalog
- Flow Designer
- ServiceNow Tables and Forms
